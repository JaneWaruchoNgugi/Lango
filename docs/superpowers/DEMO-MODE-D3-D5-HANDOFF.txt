  INCIDENTS

          (+activity "Incident reported").

 D5 — GUIDED TOUR + COMPLETION CTA
================================================================================
  GOAL: an optional, skippable 5-step guided tour that walks a prospect through
        the highest-value flow, then a celebratory close.

  Steps (from the brief):
    1 Register visitor  -> 2 Approve visitor  -> 3 View who's inside  ->
    4 Check in a delivery -> 5 View the activity timeline.
  Completion card: "YOU'VE SEEN LANGO IN ACTION 🎉 — Visitors. Deliveries.
    Incidents. Access. Accountability. All connected in one system."
    + [Book a Free Demo] (navigate to '/' then #demo, or Link to '/').

  Implementation sketch: a small tour slice (step index in the store OR a
    DemoTourContext), a floating card (fixed bottom, reuses .card) showing
    "STEP n OF 5" + copy + a button that performs/navigates to the step, plus
    Skip/Exit. Must be dismissible so users can free-explore. Start it from a
    "Take the tour" button on the entry screen or PM dashboard.
  Keep it lightweight; don't block free navigation.
